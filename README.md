# Fundos-Imobili-rios-Excel
Simulador de fundos imobiliários em Excel: projeta patrimônio e dividendos mensais em cenários de 2 a 30 anos e divide o aporte por perfil de investidor, usando VF, PROCV, intervalos nomeados e validação de dados. Os percentuais de cada perfil são ilustrativos e não são recomendação de investimento.
